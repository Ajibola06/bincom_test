Bincom Dev Center Recruitment Test

Overview
This project contains the PHP/MySQL solution for the Bincom ICT recruitment assessment.

 Solutions Included
- Question 1 (`index.php`): Displays party results for any selected polling unit.
- Question 2 (`lga.php`): Dynamically sums raw polling unit results for any selected LGA in Delta State.
- Question 3 (`add.php`): Form to input a new polling unit and record announced results for all parties.

 Local Setup Instructions
1. Clone the repository into `xampp/htdocs/`.
2. Import the provided Delta State election SQL file into MySQL.
3. Configure database credentials in `db.php`.
4. Run Apache and MySQL via XAMPP.
